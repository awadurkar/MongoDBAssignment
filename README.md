# MongoDB Advanced Assignment

MongoDB practice tasks covering schema validation, array updates, bulk writes, aggregation, indexes, and backup/restore.

- `mongodb-advanced-assignment.js` - Tasks 1–5 commands for `mongosh`
- `backup-restore-commands.txt` - Task 6 backup and restore commands
- `answers.md` - MCQ answers and execution-statistics notes

Run the commands locally with MongoDB Database Tools and `mongosh` installed.
